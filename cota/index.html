Shopify theme for furniture stores

Setting up Cota

Cota is built for stores that sell furniture. Every piece can carry its real measurements, and the theme turns them into plan drawings, size comparisons and a "Will it fit?" check, so shoppers know the sofa fits the wall and goes through the door before they buy.

Version 1.0.0 Languages English, Spanish Demo store Escuadra Get support

Quick start

These steps get a new store from install to a working furniture catalog. Each one links to its full section below.

  1. Add Cota from the Theme Store, then open Online Store › Themes › Customize.
  2. Choose centimeters or inches in Theme settings › Measurements, then pick fonts, colors and your logo. See Theme settings.
  3. Create the measurement metafields in Settings › Custom data › Products, using the keys in Measurements. It takes about ten minutes, and it is what makes the plans, sizes and fit checks work.
  4. Fill in width, depth and height on each product. Product cards, the product page and the size sections pick them up automatically.
  5. Create collections by room, by type and by size, and build your menus.
  6. Turn on the width and narrowest door filters in the free Search & Discovery app so shoppers can filter by size. See Collections and search.

Theme settings

Open the theme editor and click the brush icon (Theme settings) to change settings that apply to the whole store.

Measurements

Cota reads each piece's size from product metafields in the custom namespace. Create these definitions once in Settings › Custom data › Products › Add definition. Use exactly the namespace and key shown; the name can be anything, in any language.

Namespace and keyTypeUsed for
custom.widthDecimalCard measurements, product page, plans, size sections, Will it fit?, filters
custom.depthDecimalSame as width (front to back)
custom.heightDecimalSame as width (total height)
custom.diameterDecimalRound pieces, instead of width and depth. Shown as Ø 70 × 38
custom.seat_heightDecimalMeasurements block on the product page
custom.min_doorDecimalNarrowest door the piece goes through: Will it fit?, the cart's "For delivery" box, the door filter
custom.plan_frontFile (image)Your own front drawing for the plan views
custom.plan_sideFile (image)Your own side drawing
custom.plan_topFile (image)Your own top drawing
custom.plan_pdfFile (PDF)Download button in Plans and technical sheet

Type plain numbers, without the unit, in the unit chosen in Theme settings › Measurements. For example, a sofa 214 cm wide gets 214. If you switch the unit later, the numbers are not converted, so change them too.

Every field is optional. A product with no measurements works like a regular product, and the parts that need sizes stay hidden or show a sample drawing in the theme editor.

Plan drawings

You do not need drawings to get plans. Without plan images, Cota draws each view as a simple box with the real measurements, at the same scale. Upload your own images in the plan metafields when you want a detailed drawing.

Narrowest door

When custom.min_door is empty, Cota uses the smallest of width, depth and height, because most pieces can be carried through a door on their side. Fill it in when you know better, for example for a sofa that cannot be tilted.

Menus and collections

Main menu

Choose the menu in the Header section. Items with sub-items open a large dropdown on desktop and a sliding panel on phones.

  • Size column. Type the title of one submenu, for example By size, in Size column title. Its links appear as measurement pills inside the dropdown.
  • Menu feature. Add this block to the Header to show a product as a small technical sheet, with its measurements and price, inside a dropdown. In Menu item, type the top-level item where it should appear, for example Shop. You can use an image and text instead of a product.
  • Ruler. The header can show centimeter ticks along its bottom edge. Turn it off with Show ruler.

Suggested collections

Automated collections keep themselves up to date. The demo store uses:

  • By room: living room, dining room, bedroom, using tags such as room-living.
  • By type: sofas and armchairs, chairs and benches, tables, storage and shelving, using the product type.
  • By size: up to 60 cm, 60 to 120 cm, 120 to 200 cm, over 200 cm, using tags such as width-60-120. These feed the Shop by size section and the size pills.
  • On sale: products whose price is reduced (they have a compare-at price).

Create a size menu that links to each size collection. Use it as the header's size column, under the search box (Search results › Size menu) and as the quick links in an empty cart.

Home page sections

Add sections with Add section in the theme editor. All of them can also be used on other pages.

Turning piece hero
A line drawing of a piece that turns while measurement lines draw in, next to your heading and two buttons. Pick a product to use its measurements, name and price, or choose a shape (chair, armchair or sofa, table, shelf or cabinet, round table) and type the sizes. It can turn as the page scrolls, turn on its own with a pause button, or stay still.
Featured collection
A product grid. Add more than one Tab block to let shoppers switch between collections, for example by room.
Shop by size
Cards that link to your size collections, each with a drawing that grows from the first card to the last.
Featured sheet
One product shown as a technical sheet: photo, front, side and top views at the same scale, materials, a sheet number and a buy button.
Compare sizes
Up to five pieces drawn side by side at the same scale, from the front and the side, with an optional person for scale. Shoppers tap a piece to see its measurements.
Will it fit? (pick one)
The fit check from the product page, with buttons to choose between up to four pieces. See Will it fit?.
Image with text
Photo with a heading, text and buttons. A dimension line with your own text can run above the image.
Columns
Up to eight columns, numbered or plain. Good for "How it works" or "How we deliver".
Rich text
Heading, text, a quote and buttons, centered or left aligned.
FAQ
Questions that open and close. The first can start open.
Video
An uploaded video, or a YouTube or Vimeo link, with a cover image.
Contact form, Apps, Custom Liquid
A contact form with contact details, a space for app blocks, and a place for your own Liquid code.

The Announcement bar in the header group can rotate several messages on its own. The footer can show a dimension line with a short label, such as your city.

Below the main section, the default product template adds:

  • Will it fit? See below.
  • Product recommendations, twice: complementary products (set in Search & Discovery) and related products (chosen by Shopify).

Will it fit?

Shoppers type the width of their wall and of the narrowest door on the way in. Cota answers right away, using the product's measurements:

  • Wall. Whether the piece fits and how much space is left, or how much wall is missing. A top view draws the piece in front of the wall, at scale.
  • Door. Whether the piece goes through: "your door is 60 cm, it needs at least 80 cm", or how much room is left.

It appears in three places: the Will it fit? section on product pages, the Will it fit? (pick one) section for the home page, and the "Where does it go?" bar on collection and search pages, which marks every product card as fitting or not.

Good to know. The check compares widths only. It is a quick guide for shoppers, not a guarantee: stairs, corridors and turns can still be tighter than the door. Say so in your delivery information.

Collections and search

  • Filters come from the free Search & Discovery app. Price, availability, product type and your measurement metafields work well. Measurement filters (such as width) show as "Up to 120 cm" buttons instead of a long list of exact sizes.
  • Photo / Plan switch. Plan draws every product from the front at the same scale, so sizes are easy to compare.
  • "Where does it go?" bar. Shoppers enter their wall and door width and each card is marked as fitting or not. "Only show what fits" uses the width and narrowest door filters when they are on in Search & Discovery; otherwise it hides the cards on the current page.
  • Product cards show the piece's measurements and, when set, the unit price.
  • Choose products per page, columns on desktop, and one or two columns on phones.
  • Search results use the same product cards, filters and sorting, and can show your size menu under the search box.

Cart and gift cards

  • Cart drawer or page. Set in Theme settings › Cart. The drawer can suggest one product that goes with what is in the cart.
  • "For delivery" box. Shows the largest piece in the cart and the door it needs, from the product measurements, so shoppers can check before checkout.
  • Free shipping message. Type the amount, in your store currency, from which delivery is free. The cart shows how much is left. The theme only shows the message; create the free rate itself in Settings › Shipping and delivery. Leave it empty to hide the message.
  • Empty cart. Pick a menu, such as your size menu, to show quick links instead of a blank page.
  • Gift cards. Create a gift card product in Products › Gift cards. Customers can send one to a recipient with a message and a delivery date. The gift card page is styled to match the theme.

Blog

The blog page can feature the latest post, and show topics and excerpts. Blog posts show the reading time and share links.

To show a product next to a post, create a metafield definition for blog posts with the key custom.product and the type Product, then pick the product on each post.

Motion

Cota moves in a few deliberate places. Visitors whose device asks for reduced motion always see the still version, with every measurement shown, whatever you choose here.

Languages

The theme's own text (buttons, labels, messages) comes in English and Spanish. To sell in another language, add it in Settings › Languages and translate your products, collections and pages with the free Translate & Adapt app. You can also change any theme text in Online Store › Themes › … › Edit default theme content.

The header and footer can show a language selector and a country/region selector. Turn them on in each section's settings.

FAQ

The measurements or plans do not show on my products.

Check that the metafield definitions use the custom namespace and the exact keys in Measurements, that their type is a decimal number, and that the product has values. Width and height (or diameter and height) are enough for most drawings.

My store uses inches.

Choose Inches in Theme settings › Measurements and enter the metafields in inches. Labels, filters and the fit check switch to inches too.

Can I sell products without measurements?

Yes. Lamps, rugs, cushions and gift cards work as regular products. The parts that need sizes stay hidden.

I already store sizes in another app or namespace.

Cota reads the custom namespace. Copy the values into the keys listed above with a bulk editor or a CSV import.

How do I show a different set of sections for one product?

Create a new product template in the theme editor (Product › Create template), change it, and assign it to that product in the admin.

The free shipping message says one thing and checkout charges shipping.

The message is only a reminder. The real rule lives in Settings › Shipping and delivery. Make the amount in the theme match your free shipping rate.

Can I turn off all animations?

Turn off scroll effects, set the card hover to None, and set the turning piece to Still. See Motion.

Will updates erase my changes?

Theme updates keep your settings and content. Changes made directly in the code are not carried over, so keep a copy of anything you edit by hand.

Support

We help with setting up Cota, using its settings and sections, and anything that does not work as described in this guide. We reply within 2 business days, Monday to Friday (Uruguay time, UTC−3).
